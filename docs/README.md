# Documentation

Thư mục này dùng để lưu tài liệu chung của đồ án.

Có thể bổ sung dần trong quá trình phát triển:

- System architecture
- ERD / Database design
- TCP communication protocol
- API integration notes
- Test cases
- Deployment guide
- Demo script
- Báo cáo / hình ảnh minh họa

Không bắt buộc tạo toàn bộ tài liệu ngay từ đầu. Chỉ bổ sung khi từng phần của project được triển khai và ổn định.
